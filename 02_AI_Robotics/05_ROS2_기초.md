# 05. ROS2 기초 | 로봇 소프트웨어 입문

> 노드·토픽·서비스·액션·DDS 통신구조·퍼블리셔/서브스크라이버 패턴 | colcon 빌드·launch 파일·파라미터(Parameter) 관리·노드 라이프사이클(Lifecycle)

## 1. 학습 목표
- ROS2의 핵심 통신 구조(노드·토픽·서비스·액션)와 DDS 기반 비동기 통신 원리를 이해한다.
- publisher/subscriber 패턴으로 메시지를 송수신하는 노드를 작성할 수 있다.
- colcon 워크스페이스 빌드, launch 파일, 파라미터 관리, 라이프사이클 노드를 사용할 수 있다.
- Isaac Sim/Isaac ROS로 이어지는 ROS2 브리지 사용 기초를 닦는다.

## 2. 교육 내용 (주요 주제)

### 2.1 ROS2 기초와 통신구조
- 작업공간 개념: `overlay`/`underlay`, `source /opt/ros/humble/setup.bash`
- **노드**: 실행 단위(최소 1개 프로세스) — `ros2 node list/info`
- **토픽**: 비동기·단방향, pub/sub — `ros2 topic list/hz/info/echo`
- **서비스**: 요청-응답(request-response), 동기 — `ros2 service list`
- **액션**: 목표-결과-피드백 3단계, 장시간 작업 — `ros2 action list`
- **DDS**: QoS(Quality of Service) 정책(reliability, durability, deadline), discovery
- 메시지 타입: 표준(`sensor_msgs/Image`, `nav_msgs/Odometry`, `geometry_msgs/Twist`)와 커스텀 msg

### 2.2 퍼블리셔/서브스크라이버 패턴
- 신규 패키지 생성: `ros2 pkg create` (Python/C++)
- 퍼블리셔 노드: `rclpy.publisher`, `Rate`/`Timer`, `qos_profile`
- 서브스크라이버 노드: 콜백 기반 처리, 멀티 토픽 구독
- 클래스 기반 노드 작성 패턴 (OOP, 02장 연계)
- `ros2 launch`: `launch` 파일(YAML/XML/Python)으로 다중 노드 실행·인자 전달
- 진단·시각화: `rqt_graph`, `rqt_plot`, RViz2

### 2.3 파라미터·라이프사이클
- 파라미터: `declare_parameter`, `get_parameter`, YAML로 기본값 설정, `ros2 param list/dump`
- 노드 라이프사이클(Managed Node): `unconfigured → inactive → active → finalized`, 억제/복구 패턴(자율시스템 안전성 기초)
- 사용 예: 매니퓰레이터 이중화 제어, 내비게이션 노드(lifecycle) 연동

## 3. Hands-On 실습
1. `talker/listener`를 직접 코딩해 빌드·실행 (토픽 echo/viz)
2. 로봇 명령/제어 노드: `Twist` 발행(모터 명령) + `Odometry` 구독→플롯
3. 커스텀 msg(`PoseStamp`, `JointCmd`) 정의·사용
4. 서비스 클라이언트로 파라미터 교체, 액션 서버/클라이언트로 장시간 태스크 구현
5. launch 파일로 3개 노드 일괄 실행 + 파라미터 YAML 로드
6. (연계) Isaac Sim ROS2 브리지로 시뮬레이터 토픽 구경

## 4. 환경 및 하드웨어 준비사항
| 항목 | 권장 사항 |
|------|-----------|
| OS | Ubuntu 22.04 (WSL2도 가능하나 GUI·네트워크 이슈 시 권장 환경 사용) |
| ROS2 | **Humble** (Isaac ROS가 지원하는 기준 버전) 또는 Jazzy |
| 툴 | colcon, rosdep, RViz2, rqt, turtlesim |
| IDE | VS Code + ROS 확장, Foxglove(진단·시각화 대안) |
| 하드웨어 | CPU만으로 실습 가능. Jetson(있다면)에서도 동일 환경 |
| Isaac 연동용 GPU | Isaac Sim 6.x 최소: RTX 4080(16GB VRAM, 32GB RAM) — 권장 RTX 5080 |
