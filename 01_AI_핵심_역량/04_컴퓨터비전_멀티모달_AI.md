# 04. 컴퓨터비전 & 멀티모달 AI

> OpenCV 기반 이미지 전처리 | 객체 인식·이미지 분류·비전 AI | 이미지·텍스트·음성 기반 멀티모달 AI

## 1. 학습 목표
- OpenCV로 이미지 읽기·필터링·기하학 변환·세그멘테이션 등 전처리를 수행할 수 있다.
- 객체 감지(Object Detection)·이미지 분류·Instance Segmentation 모델의 원리를 이해하고 사전학습 모델을 활용할 수 있다.
- 이미지·텍스트·음성 등 여러 모달리티를 결합한 멀티모달 AI 시스템을 설계할 수 있다.
- NVIDIA의 비전 AI 스택(TAO Toolkit, DeepStream, TensorRT) 흐름을 이해한다.
- GPU 에지(엣지) 플랫폼(Jetson)에서 비전 모델을 배포하는 기본을 익힌다.

## 2. 교육 내용 (주요 주제)

### 2.1 OpenCV 기반 이미지 전처리
- 이미지 입출력, 색공간 변환(BGR/RGB/HSV/Gray), ROI
- 필터링: 가우시안/중앙값/양방향 필터, 히스토그램 평활화
- 기하학 변환: 회전·이동·크기조절·원근 변환(Homography)
- 임계값(Otsu), 형태학(Morphology: 침식/팽창), 윤곽선(Contour) 검출
- 특징점: SIFT, ORB, FAST, 특징 매칭(BFMatcher, FLANN)

### 2.2 객체 인식·이미지 분류·비전 AI
- 이미지 분류: CNN 파인튜닝 (03장 연계), ViT
- 객체 감지: YOLO 계열, Faster R-CNN, SSD (이론 + 사전학습 활용)
- 세그멘테이션: Semantic Segmentation(U-Net, DeepLab), Instance Segmentation(Mask R-CNN)
- 비전 파이프라인: 감지 → 추적(ByteTrack/DeepSORT) → 행동분석
- 비디오 AI: 프레임 스트리밍 처리, DeepStream 파이프라인 개념
- KITTI/COCO 데이터셋과 평가 지표(mAP, IoU)

### 2.3 NVIDIA 비전 AI 스택
- **TAO Toolkit**: 사전학습 모델을 내 데이터로 커스터마이징(전이학습), INT8 양자화
- **TensorRT**: FP16/INT8 최적화로 실시간 추론
- **DeepStream SDK**: 스트리밍 비디오 AI 파이프라인(GStreamer 기반)
- **Metropolis**: 지능형 비디오 분석(IVA) 전체 워크플로우
- **Jetson**: 에지 배포 플랫폼 (Jetson Orin Nano/NX/AGX)
- 배포 실습 예제: YOLO → TensorRT 변환 → Jetson/DeepStream에서 60fps 이상 실시간 처리

### 2.4 멀티모달 AI
- 멀티모달 학습 개념: 공유 임베딩 공간, Cross-Attention
- Vision Language Model(VLM): CLIP, LLaVA, BLIP — 이미지+텍스트
- NASA 자동 캡셔닝(Image Captioning), VQA, Visual Grounding
- 음성+텍스트: ASR(음성→텍스트), TTS(텍스트→음성)
- NVIDIA Speech NIM: ASR/TTS/NMT를 컨테이너 마이크로서비스로 제공
- 통합 멀티모달 에이전트: 음성 입력 → 인식 → LLM 추론 → 비전 → 음성 응답 (05~08장과 연계)

## 3. Hands-On 실습
1. OpenCV로 이미지 필터링·형태 변환·윤곽 검출 실습
2. 사전학습 YOLO로 커스텀 객체 감지 + TensorRT 변환으로 추론 속도 비교 (CPU/GPU/Float32/INT8)
3. CLIP을 활용한 Zero-shot 이미지 분류와 모달리티 결합 실습
4. NVIDIA AI Blueprint(멀티모달 RAG) 또는 VLM 사전학습 모델로 이미지 질문응답 구현
5. Jetson(또는 NGC 컨테이너)에서 실시간 비전 파이프라인 실행

## 4. 개발 환경 및 하드웨어 준비사항
| 구성 | 권장 사항 |
|------|-----------|
| Python | 3.10 ~ 3.12 |
| 라이브러리 | opencv-python, torch, torchvision, ultralytics(YOLO), transformers(HF), numpy |
| GPU | RTX 4080 권장 / RTX 3060 이상 가능, 클라우드는 Brev L40S |
| 실시간 추론 | TensorRT, Triton Inference Server (컨테이너) |
| 에지 배포(선택) | Jetson Orin Nano Super Dev Kit (67 TOPS, JetPack 6.x) |
| NVIDIA 계정 | NGC + Developer Program (TAO, DeepStream 설치 필요) |

> Jetson Orin Nano Super Dev Kit 요약: 67 INT8 TOPS, 1024 CUDA cores + 32 Tensor Cores, 6-Core Arm A78AE, 8GB LPDDR5(102GB/s), 7~25W, microSD/NVMe 스토리지, 4×USB 3.2 Gen2, GbE, 40-pin GPIO, 2×MIPI CSI. JetPack 6.2 이상 설치 권장.
