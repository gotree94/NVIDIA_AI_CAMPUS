# 06. NVIDIA DLI 1 | 로봇 운동학·제어 기초

> 순기구학·역기구학(FK/IK)·좌표계 변환(TF) | PID 제어 기초 · DLI 클라우드 GPU 브라우저 접속

## 1. 학습 목표
- 순기구학(Forward Kinematics)과 역기구학(Inverse Kinematics)의 원리를 이해하고 구현할 수 있다.
- 좌표계 변환(TF: Transform)과 오일러각/쿼터니언 표현을 다룰 수 있다.
- PID 제어의 원리와 튜닝 방법을 이해하고 시뮬레이션에 적용할 수 있다.
- NVIDIA DLI 클라우드 GPU(브라우저) 실습 환경에 접속·사용할 수 있다.

## 2. 교육 내용 (주요 주제)

### 2.1 좌표계와 TF
- 링크·조인트 프레임, 좌표 변환(TF 트리): `base → link1 → ... → end effector`
- 회전 표현: 회전행렬, 오일러각(RPY/ZYX), 쿼터니언 — 상호 변환
- DH 파라미터와 정규 변환행렬(4×4 Homogeneous)
- ROS2 TF2: `static_transform_publisher`, `tf2_buffer`, RViz에서 TF 시각화

### 2.2 순기구학(FK) · 역기구학(IK)
- **FK**: 관절 각도 → 엔드 이펙터 위치/자세 (체인 곱)
- **IK**: 목표 pose → 관절 각도
  - 해석적(Analytic): 2R 팔, 특정 구조
  - 수치적: Jacobian 기반(Newton, DLS), 최적화
  - 제어 계층: MoveIt(11·14장에서 심화)이 사용하는 KDL/TRAC-IK/Tesseract 소개
- 완성 예: 2-DOF 팔과 6-DOF UR 로봇의 FK/IK 파이썬 구현

### 2.3 PID 제어
- P/I/D 각 항의 역할, Zeigler–Nichols 튜닝, anti-windup
- 관절 위치 제어로의 응용: torque(PID 출력) → 관절 각도 수렴
- 시뮬레이션에서의 적용: 1차/2차 시스템, PWM 제한, 데드밴드
- (8장 연계) 강화학습 vs PID: 학습 정책이 대체하는·협력하는 제어 계층

### 2.4 DLI 클라우드 GPU 실습
- 과정: **"Fundamentals of Robotics" 계열(DLI)** 강사 주도 워크숍 개설 여부 확인
- 접속 절차: learn.nvidia.com에서 과정 등록 → 제공된 클라우드 GPU VM 접속(브라우저/Jupyter/Remote Desktop) → 과제 수행
- 실습 환경: JupyterLab, Isaac Sim/Lab 접속(포트포워딩), NGC Assets 다운로드
- 로컬 대안: GPU 없이도 FK/IK·PID는 메시(Meshcat/PyBullet)로 실습 가능

## 3. Hands-On 실습
1. 2-DOF 팔 DH 파라미터로 FK 구현·TF 트리 확인
2. Jacobian/해석식을 통한 2R IK 구현 및 도달 오차 분석
3. numpy로 쿼터니언→회전행렬 변환 및 기준 프레임 변환 검증
4. PID 제어로 관절 위치 추종 시뮬레이션(오버슈트/정상상태 오차 비교)
5. DLI 클라우드 VM에서 Isaac Sim 샘플 실행 (가능 시)
