# 02. 파이썬 프로그래밍 | 자율시스템 기초

> 파이썬 문법·자료구조·객체지향(OOP)·예외처리 | NumPy·Matplotlib·VS Code+venv 경량 개발환경·로봇 제어 스크립트

## 1. 학습 목표
- 파이썬 문법과 자료구조·OOP·예외처리를 실제 스크립트에 적용할 수 있다.
- VS Code + venv 기반의 경량 파이썬 개발환경을 구성할 수 있다.
- NumPy·Matplotlib으로 센서 데이터를 처리·시각화할 수 있다.
- ROS2 서브스크라이버 스타일의 **로봇 제어 스크립트**(시뮬레이터 연동 전 단계)를 작성할 수 있다.

## 2. 교육 내용 (주요 주제)

### 2.1 파이썬 문법·자료구조
- 기본형, 리스트·딕셔너리·셋·튜플, 슬라이싱, 컴프리헨션
- 함수·람다·`*args`/`**kwargs`, 제너레이터, 패킹/언패킹
- 자료구조 선택 기준: 리스트 vs 딕셔너리 vs 셋, 시간복잡도
- 파이썬과 CUDA 스레드 개념 비교(전체론) — 병렬 처리 이해의 밑거름

### 2.2 OOP·예외처리
- 클래스·인스턴스·상속·다형성, 매직 메서드, `@dataclass`
- 예외: `try/except/else/finally`, 커스텀 예외, 로깅(`logging`) 기본
- 코드 품질: docstring, 타입 힌트, `ruff`/`black`, 단위테스트(`pytest`)

### 2.3 NumPy·Matplotlib — 센서·상태 데이터
- NumPy: 배열 연산, 마스킹, 통계 — IMU/엔코더 데이터 전처리에 활용
- Matplotlib: 실시간 상태 플롯, 트래젝토리(경로) 시각화, 히스토그램
- 데이터 수집 기본: CSV·JSON 로깅, 센서 주파수(Hz) 관리
- 시험 삼아 .gif/.mp4 경로 시각화 (모션 재생)

### 2.4 로봇 제어 스크립트 (ROS 전 단계)
- 추상화 패턴: 로봇 제어 인터페이스(속도, 위치)를 클래스로 모델링
- 시뮬레이션 루프 작성: 센서 갱신 → 상태 추정(engine rate) → 제어 출력 → 플롯
- PID 제어의 파이썬 1차 구현 (물리 이해는 06장에서 심화)
- 메시지 스타일 소개: `(seq, time, x, y, theta)` 데이터 구조 → ROS2 msg로의 전환 준비
- 파일 구성 예:
  ```
  project/
    robot_node.py      # 제어 노드 모사
    imu_sim.py         # 가상 센서
    plots.py           # 시각화
    config.yaml        # 파라미터
  ```

## 3. Hands-On 실습
1. 로봇 상태(Pose) 클래스 + 좌표 변환(회전행렬)·경로 계획 기초 구현
2. 가상 IMU/엔코더 데이터 생성 → NumPy 필터(이동평균)→Matplotlib 플롯
3. 1차 PID 기반 라인 트래커(시뮬레이션) 제어 스크립트 작성
4. `pytest` 단위테스트 + 로깅으로 스크립트 안정성 확보
5. VS Code+venv 환경을 재현 가능하게(requirements.txt) 구성
