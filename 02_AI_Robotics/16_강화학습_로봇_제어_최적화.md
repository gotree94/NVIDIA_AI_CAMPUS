# 16. 강화학습 | 로봇 제어 최적화 프로젝트

> Isaac Lab 정책학습·모방학습(Imitation Learning)·시연 기반 학습(Learning from Demonstration) | 보상설계·Sim-to-Real 전이·대규모 장시간 학습

## 1. 학습 목표
- 강화학습(Isaac Lab) 정책학습을 심화 수행한다 — 행동(Policy) 기반 제어 최적화.
- 모방학습·시연 기반 학습(LfD, DAGGER·BC)을 이해하고 Isaac Lab으로 활용한다.
- 보상설계·도메인 랜덤화·Sim-to-Real 전이 전략을 적용한다.
- 대규모 장시간 학습(오케스트레이션·체크포인트·하이퍼파라미터)을 운영한다.

## 2. 교육 내용 (주요 주제)

### 2.1 강화학습 심화(Isaac Lab 정책학습)
- 8장 기초를 넘어: 멀티 보상 항목 튜닝, 희소 보상 + 밀집 보상 하이브리드
- 태스크 선택: 터레인 보행(Anyombo), 매니퓰레이션 탈퇴, 2인 조종(바이페드 등)
- Observation/action 도메인: proprioceptive(state), 이미지(depth/rgb) 정책 — CNN/MLP 구조
- 장시간 학습 운영: 에폭 스케줄, 반복 재시드, 평가 주기, 저장 주기(체크포인트)
- 하이퍼파라미터 임상: GAE-lambda, clip_eps, entropy coeff, lr schedule — 텐서보드로 진단

### 2.2 모방학습·시연 기반 학습
- **Behavior Cloning(BC)**: 전문가 시연 → 지도학습으로 정책 — 빠르지만 분포 이동 문제
- **DAgger**: 온라인 재시연 수집으로 분포 이동 해소(확장 개념)
- **LfD**: 시연(원격조작 데이터, Isaac TeleOp) → 보상 형상·우선 시드 초기화
- Isaac Lab 도구: `Isaac TeleOp`(실물·시뮬 원격조작 수집), `nuRec`, 시연 재생 리플레이
- 실용 절충: BC로 초기값 → RL으로 미세조정(사전 스킬), 중복 정책으로 실전

### 2.3 보상설계 응용·Sim-to-Real
- 보상설계 예제: 속도 추구 + 자세 안정 + 에너지 페널티, Milestone 보상(곡선 커리큘럼)
- 도메인 랜덤화: 질량·마찰·관절 강성·외력·라인 잡음 randomize — one policy를 다양한 센서에
- **Sim-to-Real 전이**: 현실성(피직스 파라미터 분산)→정책 강건성 확인, 모델 지연 보상(actuation delay), 실-시뮬 격차(VIS/저수준) 분석
- 테스트: 분포 외(근거 리얼 웨이트)에서 안정성, 에지(미끄럼 바닥) 평가
- (실물 있을 때) Jetson에 정책 배포: TensorRT 변환, 실행 주기(RT) 확인

### 2.4 대규모 장시간 학습 운영
- 클러스터/서버: NVIDIA Brev(L40S), 클라우드 GPU, 멀티 GPU(필요 시)
- headless·백그라운드 실행(`nohup`/`tmux`), 파라미터 로그 아카이브
- Run with: `--task=... --headless --num_envs=16384`, `--video`로 체크포인트 영상 녹화
- 학습 재개: `--resume`, 최적 체크포인트 선택·평가·배포 파이프라인

## 3. Hands-On 실습 (프로젝트 운영 방식)
캘리브레이션: 로봇 하나(게이트: 보행 or 파지) 선택해 아래 워크플로 수행
1. 태스크 선정·환경 확인: Isaac Lab basic 태스크(carter/ant/anyombo) 실행
2. baseline PPO 훈련 → 보상 설계 변경(성공률 +30%) 및 시각화
3. BC(시연 100개) → RL 튜닝 파이프라인 실습, 두 정책 성능 비교표
4. 도메인 랜덤화(질량·마찰·잡음) 적용 → 실-시뮬 강건성 테스트
5. 최종: 16384 env · 8시간 이상 학습 → 최고 체크포인트를 MP4로 평가·정리 (발표 자료)
