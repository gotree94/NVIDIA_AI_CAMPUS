# 01. 프로그래밍 & 데이터 기초

> Python 기본 문법 · 함수 · 객체지향 프로그래밍 | NumPy · Pandas 기반 데이터 처리·분석 | 데이터 전처리·정제·가공·시각화

## 1. 학습 목표
- Python 문법(자료형, 제어문, 함수, 클래스)을 자유자재로 활용할 수 있다.
- 객체지향 프로그래밍(OOP)의 핵심 개념(캡슐화, 상속, 다형성)을 이해하고 적용할 수 있다.
- NumPy를 활용한 벡터·행렬 연산과 고성능 수치 계산을 수행할 수 있다.
- Pandas를 활용해 표 형태의 데이터를 불러오고, 전처리·정제·가공하여 분석 가능한 형태로 만들 수 있다.
- Matplotlib / Seaborn을 활용해 데이터를 시각화하고 인사이트를 도출할 수 있다.

## 2. 교육 내용 (주요 주제)

### 2.1 Python 기본 문법
- 자료형: 정수/실수/문자열/Bool, 리스트·튜플·딕셔너리·셋
- 연산자, 조건문(`if`), 반복문(`for`, `while`), 컴프리헨션
- 함수(`def`, `lambda`), 파라미터/키워드 인자, 가변 인자(`*args`, `**kwargs`)
- 모듈/패키지(`import`), 표준 라이브러리(OS, JSON, re, collections 등)
- 예외 처리(`try/except/finally`), `assert`

### 2.2 객체지향 프로그래밍 (OOP)
- 클래스와 인스턴스, `__init__`, 인스턴스/클래스/정적 메서드
- 캡슐화(속성 접근, property), 상속, 다형성, 추상화
- 매직 메서드(`__repr__`, `__eq__`, `__len__` 등)
- 데코레이터, 제너레이터, 컨텍스트 매니저(`with`)

### 2.3 NumPy 기반 데이터 처리
- `ndarray` 생성·형태 조작(`reshape`, `flatten`, `transpose`)
- 인덱싱/슬라이싱, 팬시 인덱싱, Boolean 마스킹
- 벡터화 연산: 브로드캐스팅, 유니버설 함수(ufunc)
- 통계 함수(`mean`, `std`, `sum`), 선형대수(`dot`, `linalg`)
- 난수 생성(`random`)과 시드 설정 — 재현 가능한 실험의 기초

### 2.4 Pandas 기반 데이터 분석
- `Series` / `DataFrame` 생성과 인덱싱(`loc`, `iloc`)
- 파일 입출력: CSV, Excel, JSON, Parquet
- 데이터 정제: 결측치(`NaN`) 처리, 중복 제거, 이상치 식별
- 데이터 가공: `groupby`, `agg`, `merge`/`concat`, `pivot_table`, `apply`
- 시계열 처리(`datetime`, `resample`), 카테고리형 데이터
- 가속화 연계: cuDF / RAPIDS 소개 (GPU 가속 Pandas)

### 2.5 데이터 시각화
- Matplotlib: `figure`/`axes`, 선/점/막대/히스토그램, 다중 서브플롯
- Seaborn: 분포(`distplot`/`histplot`), 상관관계(`heatmap`), 범주형 플롯
- EDA 결과를 위한 시각화 디자인 원칙
- 참고: NVIDIA RAPIDS (cuDF·cuML·cuGraph)로 Pandas/scikit-learn 워크로드 GPU 가속화
  - 관련 DLI 과정: **Getting Started with Accelerated Computing with CUDA C/C++** (6시간, $90), **Fundamentals of Accelerated Data Science**

## 3. Hands-On 실습
1. 파이썬으로 계산기/정렬/파일 처리 유틸리티 작성
2. 데이터 클래스 + 외부 파일(JSON/CSV)을 활용한 간단한 도서 관리 시스템 (OOP 연습)
3. NumPy로 행렬 연산 및 이미지 회전/브라이트니스 조절 (이미지를 ndarray 취급)
4. Pandas로 공공 데이터(예: Kaggle Titanic, 서울시 데이터) 전처리 분석
5. Matplotlib/Seaborn으로 EDA 리포트 산출
