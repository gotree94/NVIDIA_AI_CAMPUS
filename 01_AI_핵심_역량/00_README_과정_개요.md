## 과정 전체 준비사항 (필수)
| 항목 | 내용 |
|------|------|
| NVIDIA 계정 | Developer Program(developer.nvidia.com)·NGC(catalog.ngc.nvidia.com)·learn.nvidia.com(DLI) 회원가입 |
| Python 환경 | 3.10~3.12 + venv, VS Code + Jupyter |
| GPU (권장) | GeForce RTX 4080 이상(16GB VRAM) — 로컬 / NVIDIA Brev 대체 가능 |
| 클라우드 GPU | NVIDIA Brev(L40S 등) — https://brev.dev |
| 무료 실습 | build.nvidia.com(NIM API) — 05~06장이면 GPU 없이 진행 가능 |
| 자격 대비 | DLI 필수 과정 4개 이수 + 모의고사 60문항 문제풀이 |
