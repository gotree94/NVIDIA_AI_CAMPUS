# 14. ROS2 로봇제어 | 모션제어·매니퓰레이션

> ros2_control·매니퓰레이터 제어 | MoveIt2 궤적 계획·그리퍼 제어·실물 로봇 인터페이싱

## 1. 학습 목표
- ros2_control 프레임워크(Controller Manager·하드웨어 인터페이스)를 이해한다.
- 매니퓰레이터의 관절 제어(위치·속도·토크)를 ros2_control로 구성한다.
- MoveIt2의 궤적 계획·실행과 그리퍼(Action) 제어를 연동한다.
- 시뮬레이션(Isaac) → 실물 로봇(Jetson 기반) 인터페이싱 흐름을 이해한다.

## 2. 교육 내용 (주요 주제)

### 2.1 ros2_control
- 구조: `hardware_interface`(Actuator/Sensor) → `controller_manager` → controllers(들)
- `controller_manager`: load/configure/activate controllers 라이프사이클
- 컨트롤러 예: `joint_state_broadcaster`, `joint_trajectory_controller`, `position_controllers/JointGroupPositionController`
- 하드웨어 인터페이스: `SystemInterface`구현(CAN/URDF실, 시뮬플러그인) or `MockHW`(시뮬레이션 테스트)
- YAML 파라미터: `ros2_control` 태그(로봇_description), joints·command·state 인터페이스 정의

### 2.2 매니퓰레이터 제어
- 관절 상태(sensor)/명령(command) 흐름: MoveIt → JointTrajectoryController → HW → 센서 피드백
- PID 관절 제어 파라미터(cmd_interface, pid_gains), 속도·토크 제한
- 시뮬레이션 검증: Isaac Sim에서 URDF+ros2_control로 오픈루프/피드백 제어
- (인간 안전) 실물 토크 제한·이그니션 세이프티·이머전시 스톱 과정

### 2.3 MoveIt2 궤적 계획·그리퍼
- MoveIt2: Planning(planner→traj) + trajectory controller 실행(FollowJointTrajectory 액션)
- 목표 지정방식: joint goal / pose goal / 컨테이너 포즈
- 그리퍼 운동: GripperCommand 액션(열기/닫기 포지션), 병렬 그리퍼 시뮬 HW 연결
- IK: TRAC-IK/KDL 선택, 중복·특이점 회피 옵션

### 2.4 실물 로봇 인터페이싱
- 인터페이스 경로: ROS2(command/state) ↔ 서보(CANopen/EtherCAT/Dynamixel SDK) ↔ 모터 드라이버
- Jetson 실물: ros2_control HW인터페이스를 Jetson에서 컴파일·실행, `jtop`으로 리소스 확인
- 시뮬-실 전이 가이드: 하드웨어 제약(레이턴시·토크)반영, 캘리브레이션(조인트 오프셋·홈 자세)
- 예제 로봇: 6-DOF 팔(UR 시리즈 유사)·그리퍼 키트(합리적 가격 실습기)

## 3. Hands-On 실습
1. 1단계: URDF(팔+그리퍼)에 ros2_control YAML 작성 → Isaac Sim에서 MockHW로 관절 구동
2. `controller_manager.spawner`로 joint_state_broadcaster + joint_trajectory_controller 활성화
3. MoveIt2 setup assistant로 팔 설정 → 목표 그리핑 시퀀스(플랜→그리퍼 열기→파지→배치) 실행
4. 플래닝 파라미터(타임 스케일·가속도) 변경 실험
5. (Jetson 실물 보유 시) 동일 패키지를 Jetson에 배포, 실물 팔 움직임 + 진단

## 4. 환경 및 하드웨어 준비사항
| 항목 | 권장 사항 |
|------|-----------|
| ROS2 | Humble + MoveIt2, ros2_control 패키지 |
| 로봇 모델 | Franka / UR5 / Xacro 팔 + 그리퍼(시뮬) |
| 시뮬레이터 | Isaac Sim(권장) 또는 Gazebo |
| GPU | 시뮬레이션 렌더링: RTX 4080 권장(Isaac) — 로봇 제어만이면 CPU도 가능 |
| 실물(선택) | 6-DOF 팔 키트(Dynamixel 기반 등), Jetson Orin Nano/NX, CAN/직렬 어댑터, 그리퍼 |
| 안전 | 실물은 감속·엔드스톱·비상 정지 버튼 반드시 준비 |
