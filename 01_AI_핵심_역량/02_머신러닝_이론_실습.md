# 02. 머신러닝 이론 및 실습

> 지도학습·비지도학습 | 회귀·분류·군집화 알고리즘 | 데이터 분할·특성 공학·모델 성능평가

## 1. 학습 목표
- 지도학습(분류·회귀)과 비지도학습(군집화·차원축소)의 개념과 차이를 이해한다.
- 대표 ML 알고리즘의 원리와 적용 시점을 이해하고 scikit-learn으로 구현할 수 있다.
- 데이터를 학습/검증/테스트로 분할하고, 특성 공학을 통해 성능을 개선할 수 있다.
- 모델의 과적합/과소적합을 진단하고 교차검증·하이퍼파라미터 튜닝을 수행할 수 있다.
- 분류/회귀/군집화의 평가지표(accuracy, precision, recall, F1, RMSE, silhouette 등)를 올바르게 해석할 수 있다.

## 2. 교육 내용 (주요 주제)

### 2.1 머신러닝 개요
- ML 정의와 학습 패러다임: 지도/비지도/강화학습
- 용어: 특성(feature), 라벨(label), 샘플, 모델, 손실함수
- 머신러닝 vs 전통 프로그래밍 vs 딥러닝
- bias-variance 트레이드오프, 과소/과적합

### 2.2 지도학습 — 회귀(Regression)
- 선형회귀(Linear), 다항회귀(Polynomial)
- 정규화 회귀: Ridge(L2), Lasso(L1), ElasticNet
- 평가: MAE, MSE, RMSE, R²
- scikit-learn: `LinearRegression`, `Ridge`, `Lasso`, `train_test_split`, `cross_val_score`

### 2.3 지도학습 — 분류(Classification)
- 로지스틱 회귀, KNN, 결정트리(Decision Tree)
- 앙상블: 랜덤 포레스트(Random Forest), Gradient Boosting, XGBoost/LightGBM
- SVM(서포트 벡터 머신), 나이브 베이즈
- 평가: confusion matrix, accuracy, precision, recall, F1, ROC-AUC
- 불균형 데이터 처리: class_weight, SMOTE

### 2.4 비지도학습 — 군집화·차원축소
- K-Means, 계층적 군집화(Hierarchical), DBSCAN
- 차원축소: PCA, t-SNE, UMAP
- 평가: 실루엣 계수(Silhouette), elbow, inertia

### 2.5 데이터 분할·특성 공학·검증
- 데이터 분할: train/validation/test, StratifiedKfold, K-Fold 교차검증
- 특성 공학: 스케일링(Standard/MinMax/Robust), 인코딩(One-Hot, Label, Ordinal), 결측치 대체
- 특성 선택/추출: `SelectKBest`, RFE, `feature_importance`
- 파이프라인(`Pipeline`)과 하이퍼파라미터 탐색(GridSearchCV, RandomizedSearchCV, Optuna)
- GPU 가속 연계: cuML(https://developer.nvidia.com/rapids/cuml)로 동일 API GPU 실행

## 3. Hands-On 실습
1. 캘리포니아 주택가격 / 당뇨 데이터로 회귀 모델 5종 성능 비교 (RMSE, R²)
2. Kaggle Titanic으로 분류 파이프라인 구축 (결측치→인코딩→스케일링→모델→제출)
3. 이진분류 모델의 threshold 이동에 따른 precision/recall 변화 분석
4. K-Means vs DBSCAN 비교 실습 및 실루엣 계수 평가
5. GridSearchCV/Optuna로 랜덤포레스트 하이퍼파라미터 튜닝
