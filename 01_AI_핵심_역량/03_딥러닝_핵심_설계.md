# 03. 딥러닝 핵심 설계

> 인공신경망·역전파·경사하강법 | 딥러닝 모델 설계·학습·최적화 | CNN 기반 이미지 데이터 분석

## 1. 학습 목표
- 인공신경망(ANN)의 구조와 순전파·역전파·경사하강법의 동작 원리를 수식과 직관으로 이해한다.
- 활성화 함수, 손실함수, 옵티마이저의 역할을 이해하고 상황에 맞게 선택할 수 있다.
- PyTorch를 이용해 딥러닝 모델을 직접 설계·학습·평가할 수 있다.
- CNN의 핵심 연산(합성곱, 풀링, 배치정규화, 드롭아웃)을 이해하고 이미지 분류 모델을 구현할 수 있다.
- 학습 과정(학습률, 배치 크기, 정규화, 과적합 방지)을 최적화할 수 있다.
- GPU 환경에서 학습을 가속하는 기본 기법(CUDA, amp, DataLoader)을 사용할 수 있다.

## 2. 교육 내용 (주요 주제)

### 2.1 인공신경망 기초
- 퍼셉트론 → 다층 퍼셉트론(MLP) → 딥러닝으로의 확장
- 뉴런, 가중치·바이어스, 레이어 구성
- 활성화 함수: Sigmoid, Tanh, ReLU 계열, Softmax, GELU/SiLU
- 손실함수: MSE, Cross-Entropy, Categorical/Binary Cross-Entropy

### 2.2 역전파와 경사하강법
- 연쇄 법칙(Chain Rule) 기반 역전파(Backpropagation)
- 경사하강법(SGD)과 변형: Momentum, RMSProp, Adam, AdamW
- 학습률 스케줄링(Step/Plateau/Cosine/OneCycle), Warmup, weight decay
- 기울기 소실/폭주(Gradient Vanishing/Exploding) 문제와 대응
- 신경망의 수렴 이론: Universal Approximation Theorem, feature learning

### 2.3 딥러닝 모델 설계·학습·최적화
- PyTorch 기본기: `nn.Module`, `Dataset`/`DataLoader`, `optimizer`, `loss`
- 학습 루프 작성: train/valid loop, 체크포인트, Early Stopping
- 정규화: L1/L2, Dropout, Batch Norm/Layer Norm, Data Augmentation
- 하이퍼파라미터 튜닝과 재현성(seed 고정)
- Mixed Precision(AMP) 학습, Multi-GPU(DDP) 소개
- 실험 관리: TensorBoard, Weights&Biases, MLflow
- NVIDIA 연계: TensorRT·Triton을 통한 추론 서빙, Nsight 툴로 병목 분석

### 2.4 CNN 기반 이미지 분석
- CNN 구조: Conv2d, Padding/Stride, Pooling, Flatten
- 유명 아키텍처: LeNet, AlexNet, VGG, ResNet(Residual), DenseNet, EfficientNet, ViT 소개
- 전이학습(Transfer Learning)과 파인튜닝 — 실무에서 가장 많이 쓰는 기법
- 이미지 분류 실습: CIFAR-10 / ImageNet 일부
- 객체 탐지·분할 응용 전망: Fast R-CNN, YOLO, U-Net, SegFormer (04장에서 심화)

## 3. Hands-On 실습
1. NumPy로 직접 구현하는 2층 신경망(순전파+역전파+경사하강법) — 수식 이해
2. PyTorch로 MNIST MLP 분류기 구현 (정확도 98%+ 목표)
3. PyTorch로 CIFAR-10 CNN 구현 (Data Augmentation + ResNet 기반 90%+ 목표)
4. 전이학습: ImageNet 사전학습 모델로 커스텀 이미지 분류 문제 해결
5. 학습률·배치·규제 변화에 따른 학습 곡선 실험 (과적합 진단)

## 4. 개발 환경 및 하드웨어 준비사항

### 4.1 필수 개발 환경
| 구성 | 권장 사항 |
|------|-----------|
| Python | 3.10 ~ 3.12 + venv |
| 딥러닝 프레임워크 | PyTorch 2.x (Conda/공식 설치 안내로 CUDA 환경 구성) |
| 라이브러리 | torchvision, torchaudio, numpy, opencv-python, matplotlib, tqdm, tensorboard |
| CUDA | PyTorch가 요구하는 CUDA 버전 (예: CUDA 12.x) |
| IDE | VS Code + Jupyter + GPU 모니터링(nvidia-smi, jtop) |

### 4.2 GPU 하드웨어 권장 사양
| 등급 | GPU | VRAM | 용도 |
|------|-----|------|------|
| 최소(RTX) | GeForce RTX 3060/4060/4070 | 12~12GB | MNIST/CIFAR/소규모 CNN, 파인튜닝 |
| 권장 | **GeForce RTX 4080/4090, RTX 5080** | 16~24GB | 대형 CNN·ViT·다중 실험 |
| 데이터센터 | A10/L40S/A100 | 24~40GB | 대규모 학습 (Brev 등 클라우드) |
| 클라우드 대안 | NVIDIA Brev L40S, NGC 컨테이너 | - | 로컬 GPU 없을 때 |

> 참고: Isaac Sim 최소사양이 RTX 4080(16GB VRAM, 32GB RAM)이므로 이후 로봇 과정까지 고려하면 **RTX 4080/5080급 이상**을 권장합니다.

### 4.3 환경 구축 팁
- NVIDIA 드라이버 최신 설치, `nvidia-smi`로 CUDA 확인
- Conda로 PyTorch 설치: `conda install pytorch torchvision pytorch-cuda=12.1 -c pytorch -c nvidia`
- VS Code GPU 자원 확인: NVIDIA System Management Interface, Nsight Compute
