# 01. 리눅스 기초 | 로봇 개발환경 구축

> 리눅스 커널·쉘 명령어·파일시스템·권한관리 | WSL2/VirtualBox 기반 환경 구축·SSH 원격접속·패키지 관리

## 1. 학습 목표
- Linux 커널·파일시스템 구조를 이해하고 필요한 기본 개념(프로세스, 권한, 마운트)을 설명할 수 있다.
- Windows 환경에서 WSL2(VirtualBox는 대안)로 Ubuntu 개발환경을 구축할 수 있다.
- SSH 원격접속·키 인증·포트 포워딩으로 로컬↔로봇(Jetson)/클라우드 GPU를 연결할 수 있다.
- 패키지 관리(`apt`, `pip`, `docker`)와 환경변수를 자유롭게 다룰 수 있다.

## 2. 교육 내용 (주요 주제)

### 2.1 리눅스 기본
- 커널·쉘·파일시스템 개념: `/`, `/home`, `/etc`, `/var`, `/opt`, `/dev`, `/proc`
- 표준 스트림(stdin/stdout/stderr), 파이프(`|`), 리다이렉션(`>`, `>>`)
- 기본 명령어: `ls`, `cd`, `pwd`, `cp`, `mv`, `rm`, `mkdir`, `find`, `grep`, `tar`
- 사용자·권한: `chmod`, `chown`, `sudo`, 파일 모드(755/644), ACL(기본)
- 프로세스·서비스: `ps`, `top`/`htop`, `kill`, `systemctl`, `cron`, `nohup`
- 네트워크: `ip`, `ss`, `ping`, `curl`, `wget`, `iptables`(기본), `/etc/hosts`

### 2.2 개발환경 구축 (WSL2)
- WSL2 설치: `wsl --install` (Windows 10/11), Ubuntu 22.04/24.04 배포판 설치
- WSL 구성: `~/.wslconfig` 메모리·CPU 설정, Windows 파일시스템(`/mnt/c`) vs Linux 파일시스템 사용 권장
- VS Code 연동: Remote-WSL 확장, GPU(CUDA) 지원 확인 — WSL2는 NVIDIA GPU 통과(GPU passthrough) 지원
- VirtualBox 대안: OS 미지원 환경에서 Ubuntu VM 생성 (성능은 WSL2 권장)
- 개발 도구: build-essential, git, curl, python3-pip, openssh-server, docker

### 2.3 SSH 원격접속
- `ssh-keygen`, `~/.ssh/authorized_keys` 공개키 등록
- 원격 실행: `ssh user@host`, `scp`, `rsync`, `ssh -X`(X11), VS Code Remote-SSH
- 포트 포워딩: 로컬 → 클라우드 GPU(Jupyter 8888, Streamlit), Jetson 연결
- SSH 구성 최적화: `~/.ssh/config` 호스트 별칭, `ControlMaster`

### 2.4 패키지 관리
- apt: `apt update`, `apt install`, `apt search`, PPA
- pip: `pip install <pkg>`, requirements.txt, venv 환경
- Docker: 이미지/컨테이너 기본, GPU 컨테이너 실행(`--gpus all`), **NGC NVIDIA 컨테이너**에서 Isaac/Jetson 런타임
- 환경변수: `export`, `source`, `.bashrc`/`.profile` 및 **ROS2 워크스페이스 소싱**의 기초

## 3. Hands-On 실습
1. WSL2 + Ubuntu + CUDA 확인(`nvidia-smi`)까지 환경 구축
2. 사용자/권한 실습: 팀원과 공유 폴더 권한 시나리오
3. SSH 키 생성→클라우드(Brev) 접속→Jupyter 포트포워딩까지 1인 파이프라인 완성
4. Docker로 NGC 컨테이너(PyTorch) 실행해 `nvidia-smi` 확인
5. 로봇(Jetson이 있다면) SSH 연결·모니터링 스크립트 작성

## 4. 환경 및 하드웨어 준비사항
| 항목 | 권장/필수 |
|------|-----------|
| Host OS | Windows 11 (WSL2 권장), macOS·Ubuntu 대안 |
| 개발 OS | Ubuntu 22.04 또는 24.04 (WSL2) |
| 드라이버 | NVIDIA 최신 드라이버 (WSL2 CUDA 포함) |
| 소프트웨어 | VS Code(Remote-WSL/SSH), Putty(선택), Git, Docker Desktop(WSL backend) |
| 하드웨어 | GPU 노트북(선택), 클라우드 테스트는 Brev, 로봇은 Jetson Orin Nano |
| 로봇(HW) | Jetson Orin Nano Developer Kit / Super Kit + 공유기·이더넷 케이블 |
