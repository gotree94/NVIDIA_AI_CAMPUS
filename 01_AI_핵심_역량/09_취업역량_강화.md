# 09. 취업역량 강화

> AI·Agent 개발 직무 현업 특강 | 이력서·포트폴리오 작성 | 기술면접·프로젝트 발표 | NVIDIA 협약기업 탐방·직무 이해

## 1. 학습 목표
- AI·AI Agent 개발 직무의 현황과 필요 역량을 이해하고 자신의 강점 위치를 정한다.
- 프로젝트 기반 이력서와 포트폴리오를 체계적으로 완성한다.
- 기술면접(ML/LLM/에이전트)에 대비하고 프로젝트 발표 역량을 키운다.
- NVIDIA 협약기업(파트너/고객사)의 직무와 R&D 방향을 이해한다.

## 2. 교육 내용 (주요 주제)

### 2.1 AI·Agent 개발 직무 이해 (현업 특강)
- 직무군 분류와 요구 역량
  - **ML Engineer**: 데이터 파이프라인, 모델 훈련·검증, MLOps
  - **LLM/GenAI Engineer**: RAG·파인튜닝·프롬프트·에이전트 개발
  - **AI Agent Developer**: LangGraph/CrewAI 등 에이전트 프레임워크, Tool·Memory 설계
  - **컴퓨터비전/에지 엔지니어**: TensorRT, Jetson, DeepStream
  - **로봇 AI 엔지니어**: Isaac Sim/Lab, ROS2 (2교시 이후)
- 현업 실무 사례: 에이전트 서비스 기획·납품·운영 회고
- 협약기업 트렌드: 클라우드 GPU 활용, LLM 비용 최적화, RAG 품질 관리

### 2.2 이력서·포트폴리오 작성
- **이력서 작성 원칙**
  - STAR(상황·과업·행동·결과) 기반 성과 중심 작성
  - 수치화: 정확도 %, 지연시간 ms, 비용 절감 %, 사용자 수
  - 한 장 요약 프로필(기술 스택·도메인·강점)
- **포트폴리오 구성 (GitHub 기반 권장)**
  1. 자기소개 README (기술 스택 배지, 프로젝트 목록)
  2. 프로젝트별 README: 문제정의 → 아키텍처 → 결과 → 회고 (스크린샷/데모 영상)
  3. 개인 프로젝트 2~3개 + 캡스톤 1개
  4. 블로그/발표자료(슬라이드쉐어) 연계
- **필수 아이템**: 실제 데모 링크, 재현 환경(requirements.txt/Dockerfile), 데이터 출처

### 2.3 기술면접 대비
- **면접 질문 유형**:
  - 기본기: 파이썬 문법, OOP, NumPy/Pandas, 시간복잡도
  - ML: 과적합 해결?, 편향-분산?, 교차검증?, 지표 선택?
  - DL: 역전파 설명?, CNN/Transformer 구조?, 전이학습 이유?
  - LLM: RAG vs 파인튜닝?, 환각 줄이는 법?, 토큰/컨텍스트?
  - 에이전트: 에이전트 vs 단일LLM?, Tool 호출 원리?, 멀티에이전트 설계 경험?
  - NVIDIA 스택: NIM이 뭔지?, TensorRT 최적화 경험?, Jetson 배포 경험?
- **프로젝트 발표 대비**: 5분/10분/30분 버전 준비, 데모 실패 안전장치(동영상 백업)
- **코딩 테스트**: 자료구조/알고리즘, 구현 문제 위주 연습

### 2.4 직무 분석·탐방
- 협약기업 조사 방법: 채용 공고 분석(수요 기술 스택), 기업 블로그·GTC 발표
- 탐방 전 준비: 회사 기술 스택과 NVIDIA 연관성(사용 모델·GPU·파트너십) 조사
- 네트워킹: 질문 준비(직무 일상, 성장 경로, 팀 문화), LinkedIn 활용

## 3. Hands-On (활동)
1. 기업 5곳 채용 공고의 요구 기술 스택을 표로 정리하고 내 역량과 매핑
2. STAR 이력서 초안 작성 + 수치화 리뷰 (동료 피드백)
3. 캡스톤을 포트폴리오 문서·데모 영상으로 업그레이드
4. 모의 기술면접(2문항씩 서로 진행) 및 피드백
5. 발표 피칭 5분 연습 (타이머, Q&A 대응)
