# 10. NVIDIA DLI 5 | 자율 로봇 심화과정

> 매니퓰레이션 심화·경로계획(Path Planning)·MoveIt 모션 플래닝 | 산업용 자율로봇 통합 시나리오·성능 최적화

## 1. 학습 목표
- 로봇 매니퓰레이션(Manipulation) 심화 개념(그리핑·태스크 계획)을 이해한다.
- 경로계획(Path/Motion Planning) 이론과 MoveIt(기반 MoveIt2) 활용법을 익힌다.
- 산업용 자율로봇(AMR·팔·이동 조작) 통합 시나리오를 설계·구현한다.
- 시뮬레이션 성능(물리·쓰루풋)을 최적화하는 방법을 적용한다.

## 2. 교육 내용 (주요 주제)

### 2.1 매니퓰레이션 심화
- 그래픽/저수준 그리핑: 병렬 그리퍼·흡착(Air Pick)·피쳐아 프로포지셔널 핸들
- 이동 조작(Mobile Manipulation): 자율주행 + 집기/배치 결합
- 태스크 계획(Task Planning): 상태공간 기반 하이레벨 플래너(Python 연동)와 로모 로우레벨의 조합
- Isaac Lab 매니퓰레이션 환경: Franka/UR + 장면(물체 파지) 학습 예(16장과 연계)

### 2.2 경로계획 & MoveIt
- 경로계획 기본: 공간(Configuration Space/C-Space), RRT/RRT*, PRM, A*, CHOMP/OMPL
- **MoveIt(MoveIt2)**: ROS2 기반 모션 플래닝 프레임워크
  - 구성: URDF(로봇) + SRDF(조인트제한·그룹) + MoveIt2 Config → plan/execute
  - 플랜 세팅: traj의 시간·속도 스케일링, collision avoidance, IK 솔버(TRAC-IK) 선택
  - ROS2 액션: `FollowJointTrajectory`로 제어 노드에 전달
- MoveIt과 Isaac Sim 통합: `moveit2` + Isaac Sim 샘플 패키지로 시뮬 hw interface 동작

### 2.3 산업용 자율로봇 통합 시나리오
- 통합 씨나리오 예: **팩킹 라인**: AMR(자율주행)→ 도킹 → 팔이 피킹 → 컨베이어 배치
- 아키텍처: 인식(비전) → 계획(Nav2+MoveIt) → 제어(PID/학습) → 안전(충돌·감속)
- ROS2 노드 구성: 상태머신(smach · BehaviorTree), 모니터링(진단)
- 배포 대상: 시뮬레이션 전 단계 — Isaac Sim + ISAAC Lab + 전용 ROS2 oyu

### 2.4 성능 최적화
- 물리 최적화: 시간 스텝·`physx` 속성, 접촉 바디 제한, 병렬 스트립
- 렌더링 최적화: headless, RTX가 아닌 광선 품질 하향, 센서 해상도 제한
- GPU 병렬: Isaac Lab num_envs 상향, 멀티 GPU 배치, 환경 스텝(collect steps) 최적화
- ROS2 성능: DDS(QoS reliability, best_effort), 퍼블리시 레이트, zero-copy/`image_transport` 압축
- 프로파일: `nsys`, `nvtx`, `rqt_perf`, `ros2 topic hz`

## 3. Hands-On 실습
1. (Isaac) Franka/UR을 MoveIt2로 임포트 → 목표 그리핑 플랜 생성·실행 (상태 시작→파지→배치)
2. OMPL(RRTConnect 등) 플래너 파라미터 변경 → 경로 시간·smoothness 비교
3. Nav2+MoveIt 통합: AMR가 목표 지점 이동 후 팔로 물체 집기 시나리오 구현(Isaac Sim)
4. 통합 시나리오 미니 프로젝트: 피킹/카트 태스크 보상 지표 측정
5. 성능 최적화: 물리 스텝·렌더 해상도·num_envs 변화에 따른 FPS/SPS 측정표 작성

## 4. 환경 및 하드웨어 준비사항
| 항목 | 권장 사항 |
|------|-----------|
| Isaac Sim | 최신판 + ROS2 워크스페이스(Isaac Sim 내 샘플) |
| MoveIt2 | ROS2 Humble + MoveIt 문서 설치; URDF/SRDF 설정 |
| GPU | RTX 4080+/L40S(클라우드) — 시뮬 복잡도 높은 시나리오 권장 |
| RAM/저장 | 32~64GB RAM, SSD 100GB+ |
| Jetson(선택) | 실물 이식 테스트 할 경우 Orin NX/AGX |
| 안전 | 실물 실습 시 세이프티 회로·이머전시 스톱 필수 |
