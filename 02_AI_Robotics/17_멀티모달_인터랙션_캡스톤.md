# 17. 멀티모달 인터랙션 | 로봇 행동제어 캡스톤

> 멀티모달 인터랙션(음성·비전·제스처)·모방학습 기반 행동 생성(VLA) | HRI 시나리오·Jetson Orin Nano 실물 로봇 시연

## 1. 학습 목표
- 음성·비전·제스처 등 멀티모달 입력을 융합하는 로봇 인터랙션 시스템을 설계한다.
- VLA(Vision-Language-Action) 모델 기반 행동 생성을 이해하고 실전에 적용한다.
- Human-Robot Interaction(HRI) 시나리오를 기획·검증한다.
- Jetson Orin Nano에서 실물 로봇으로 종합 데모를 완성한다.

## 2. 교육 내용 (주요 주제)

### 2.1 멀티모달 인터랙션(음성·비전·제스처)
- 입력 모달리티와 융합구조: 음성ASR + 비전(객체/사람) + 제스처(2D/3D pose) → 공용 임베딩 → 행동 정책
- 음성: Whisper/ASR 소형 모델, intent 인식 → 명령 해석
- 비전: 09·15장 기반 검출·3D위치 + pose estimation(사람 감성?)
- 제스처: hands/body pose 추정(예: MediaPipe로 손 벡터) → 명령 매핑
- 멀티모달 퓨전 설계: 어떤 모달 '우선'/'합의'? 지연·불확실 처리, 폴백(음성 실패 시 비전 우선)
- **NVIDIA 스택**: Speech NIM(ASR·TTS), VLM(NIM), Jetson에서 양자화 실행

### 2.2 모방학습 기반 행동 생성 (VLA)
- **VLA(Vision-Language-Action)**: 텍스트/비전 입력 → 행동 토큰 출력 (예: RT-1/RT-2, OpenVLA 개념)
- 기본 개념: Denoising/autoregressive로 행동 생성, instruction following
- 학습 파이프라인: 시연(원격조작) 수집 → VLA 파인튜닝 → 배포(Jetson)
- 현실적 접근: 소형 VLM + 별도 행동 정책(간접), 또는 전문 시연 기반 policy
- Isaac TeleOp/nuRec로 시연 수집 → Isaac Lab에서 BC/RL로 강화(16장 연계)

### 2.3 HRI 시나리오 설계
- 시나리오 예: "문서 전달 로봇" — 사용자 음성 "파란 공을 배달해줘" → 비전으로 공 인식 → 파지 → 배달 후 TTS로 완료 보고
- HRI 요소: 안전(접근 속도·정지), 기대·오류(의도 해석 실패 폴백), 피드백(표정/음성/조명)
- 평가: 태스크 성공률 + 사용자 만족도 + 방해(Robustness) 테스트

### 2.4 Jetson Orin Nano 실물 시연
- 하드웨어 구성: Jetson Orin Nano Super(67 TOPS) + 카메라 + 마이크/스피커 + 모바일 베이스 or 팔/그리퍼
- 소프트웨어: JetPack 6.2+, ROS2 Humble(Docker), TensorRT 변환된 모델(YOLO·VLM·ASR)
- 파이프라인: 멀티모달 통합 노드(명령 해석→인식→계획→제어→피드백)를 단일 또는 멀티 노드로 구성
- 퍼포먼스 리밋: 8GB RAM, 경량 모델 선택(INT8), 실시간 보장(지연 < 500ms 목표)
- 비상 안전: 킬 스위치, 토크/속도 제한, 콜리전 감지

## 3. Hands-On 캡스톤 (팀)
**목표**: "음성 명령 한 마디로 작업을 수행하는 로봇" 데모

| 단계 | 내용 |
|------|------|
| 1. 기획 | 사용자 시나리오 3개 작성, HRI 요구사항, 안전 규칙 |
| 2. 설계 | 멀티모달 아키텍처(ASR→LLM명령→Vision 인식→Action)→ROS2 노드 설계 |
| 3. 개발 | 시뮬(Isaac)에서 파이프라인 구현·동작 검증, Jetson용 TensorRT 변환 |
| 4. 테스트 | 정상·오류·혼선 명령 테스트(성공률·지연 시간 측정) |
| 5. 시연 | Jetson 실물 로봇으로 라이브 데모 + 발표 자료(아키텍처·한계·회고) |

## 4. 환경 및 하드웨어 준비사항

### 4.1 하드웨어 (Jetson Orin Nano Super Dev Kit 기준)
| 항목 | 사양 |
|------|------|
| Jetson | Orin Nano Super Dev Kit — AI 67 TOPS, 8GB LPDDR5(102GB/s), 7~25W, Ampere 1024 CUDA |
| 카메라 | USB 웹캠 또는 CSI(IMX219 등) |
| 오디오 | USB 마이크(Respeaker 등) + 3.5mm 스피커 |
| 이동/매니퓰 | 소형 모바일 베이스(Waveshare 등) 또는 4~6축 팔 키트(Dynamixel) + 그리퍼 |
| 보조 | 외장 NVMe SSD(권장), 19V 어댑터, 공유기+이더넷 케이블 |
| 개발 PC | RTX 4080급(미리 시뮬·캘리브레이션) |

### 4.2 소프트웨어 준비 체크리스트
- [ ] JetPack 6.2+ flashing (SD 카드 이미지 or SDK Manager)
- [ ] `jtop`, Docker+NVIDIA Container Toolkit, ROS2 Humble(컨테이너) 설치
- [ ] 경량 추론: TensorRT(INT8), VLM 소형(Nano 구동 가능), Whisper 소형
- [ ] 시뮬: Isaac Sim(Nano 시뮬은 불가 → 데스크톱에서), Isaac ROS
- [ ] 통합 레포: launch 파일·파라미터·진단 로깅 세팅
